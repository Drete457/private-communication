# Code of Conduct

## Our Standard

This project is committed to a respectful, technically serious, and inclusive
community. We expect participants to communicate in a way that makes review,
discussion, and collaboration possible for everyone.

Examples of expected behavior:

- being respectful in disagreement;
- giving clear, evidence-based technical feedback;
- assuming good faith while still being precise about risks and defects;
- accepting review comments without personal attacks;
- keeping discussions focused on the work and the users affected by it.

Examples of unacceptable behavior:

- harassment, intimidation, or personal attacks;
- hateful, discriminatory, or sexualized language;
- doxxing or sharing private information without consent;
- trolling, deliberate disruption, or bad-faith escalation;
- publishing private security reports, secrets, or sensitive user data.

## Project-Specific Expectations

Because this repository deals with privacy and security-sensitive behavior,
contributors are expected to act carefully with logs, screenshots, test data,
and bug reports.

- Do not post plaintext messages, attachments, private keys, passphrases, or raw backups.
- Do not disclose undisclosed vulnerabilities publicly; use the process in [SECURITY.md](SECURITY.md).
- Do not pressure maintainers to merge security-sensitive changes without adequate review.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests,
or other contributions that violate this code of conduct.

Depending on severity and pattern, maintainers may:

- ask for a correction;
- lock or limit a conversation;
- close an issue or pull request;
- temporarily or permanently restrict participation.

## Reporting Conduct Problems

If you experience or observe unacceptable behavior, contact the maintainer
privately through GitHub rather than escalating in public threads.

Include links, screenshots, or other relevant context where possible. Reports
will be reviewed as confidentially as practical.

## Scope

This code of conduct applies to repository discussions, issues, pull requests,
reviews, and other project spaces where community interaction happens under this
project.
